# BETWEEN — 動くヒーローエリア

index.html をブラウザで開くと動きます。GitHub Pagesなどの静的ホスティングにも配置できます。
デザイン資料庫のコード展開機能はHTTP経由で利用してください。

## ファイル

- index.html: 構造と文章
- styles.css: ベーススタイル
- motion.css: レイアウト、背景レイヤー、スマホ対応
- motion.js: WebGL / GLSLによる描画と操作（外部依存なし）
- assets/hero-keyframe.jpg: WebGLが使えない環境の代替画像

24秒で光・粒子・等高線が一巡し、各場面の後半で約2.7秒のクロスフェードを行います。
一時停止、再開、背景選択に対応し、端末のprefers-reduced-motionを尊重します。
単独で別のサイトに置くときは、ヘッダーにあるデザイン資料庫へのリンクを書き換えてください。
